Patrones de arquitectura de referencia

Documento ejemplo para que el agente proponga soluciones reutilizando patrones aprobados.

Intención El agente debe reconocer cuál patrón se ajusta mejor al caso, cuándo usarlo y qué riesgos vigilar al implementarlo.
CódigoPatrónDescripciónCuándo usarloPuntos de atención
PA-01Portal + procesos + datosCanal digital para clientes o colaboradores con autenticación, formularios, automatización y trazabilidad.Atención ciudadana, onboarding, autoservicio, solicitudes internas.Gobierno de identidades, validación documental y segregación de funciones.
PA-02Caso 360 con CRMGestión centralizada de casos, interacciones, SLA y conocimiento.Servicio al cliente, PQRS, gestión de reclamos y backoffice.Modelo de datos, colas, reglas de asignación y reporting.
PA-03Hub de integración API/eventosCapa de servicios y eventos para orquestar múltiples sistemas.Modernización, desacoplamiento de legacy, integración omnicanal.Diseño de contratos, monitoreo y control de latencia.
PA-04Data foundation + BIIngesta, curación y exposición de datos para analítica y decisiones.Indicadores ejecutivos, operación, calidad y forecasting.Calidad de fuentes, semántica común y gobierno del dato.
PA-05Copilot/Agent groundedAgente especializado con conocimiento autorizado, instrucciones y límites operativos.Asistencia experta, consulta de políticas, soporte a decisiones.Cobertura documental, versionamiento y revisión humana.

Guía rápida de selección

  1. Si el reto principal es experiencia y captura de solicitudes, comenzar por Portal + procesos + datos.
  2. Si el problema es gestión, seguimiento y SLA, comenzar por Caso 360 con CRM.
  3. Si existen múltiples sistemas y dependencias, priorizar Hub de integración API/eventos.
  4. Si la necesidad es visibilidad y gobierno del dato, usar Data foundation + BI.
  5. Si el valor está en escalar conocimiento experto, usar Copilot/Agent grounded.

Patrón recomendado para el taller

Para el caso del “AI Architecture Advisor”, el patrón base es Copilot/Agent grounded combinado con Data foundation documental y, cuando aplique, con Hub de integración para futuras acciones o consultas transaccionales.
